结果应结合以下限制理解：

- 原 Sol 实验有 302/360 份回答满分，说明题目和评分规则存在明显天花板，小分差的区分力有限。
- 同一裁判与 Sol 属于同模型系列，可能有偏好；复评用于检查一致性，不能代替人工效度验证。
- Luna 有 100/120 份回答报告的 reasoning token 为 0。该字段来自提供方计量，不能据此判断模型是否思考。
- Luna 运行时独立报告实际模型的记录为 0/120，只能核对请求和配置为 gpt-6-luna high，无法从现有日志独立证明上游真实模型与推理预算。
- TTFT 和 TPOT 在本批次与原批次均缺失，保留为 null。首段可见文本等待是单独指标，不能当作真实 TTFT，也不应将缺失值画成 0。
- 原 Sol 覆盖三个思考档位，本次 Luna 仅覆盖 high，跨模型比较应优先使用 Sol high 对 Luna high；本次无法检验 Luna 的思考深度变化。
- 输入 token 包含运行时指令开销，输出及推理 token 依赖提供方计量；不同 API 运行日期和路由应随数据一并保留。
